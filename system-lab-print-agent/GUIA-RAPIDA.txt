SYSTEM LAB PRINT AGENT 2.0 - GUÍA RÁPIDA
=======================================

INSTALACIÓN O ACTUALIZACIÓN

1. Extraiga completamente este ZIP. No ejecute el instalador desde la vista
   previa del archivo comprimido.
2. Abra la carpeta extraída.
3. Haga doble clic en INSTALAR-PRINT-AGENT.bat.
4. Al terminar se abrirá automáticamente System Lab Print Agent.

No es necesario desinstalar la versión anterior. La impresora que ya estaba
configurada se conserva automáticamente como la ruta Cocina.

RUTAS DE IMPRESIÓN

El agente incluye tres rutas independientes:

- Comprobante del cliente: comprobante que sale después de cobrar.
- Cocina: productos preparados en cocina.
- Bar / bebidas: bebidas y productos preparados en bar.

Cada ruta puede usar una impresora diferente, con su propio ancho de papel,
corte y tipo de conexión. También puede agregar rutas nuevas, por ejemplo
Postres o Parrilla.

CONFIGURACIÓN

1. En cada ruta seleccione la impresora correspondiente.
2. Elija 80 mm o 58 mm según el papel de esa impresora.
3. Pulse Guardar todas las rutas.
4. Pulse Imprimir prueba de esta ruta en cada impresora configurada.
5. No continúe hasta que cada prueba salga por la impresora correcta.

VINCULACIÓN CON EL POS

1. En el panel del agente, pulse Mostrar y copiar.
2. Regrese a System Lab POS > Mi cuenta > Vincular estación.
3. Pegue la clave y pulse Guardar y probar conexión.
4. El estado debe mostrar las rutas configuradas.

ASIGNACIÓN DE PRODUCTOS

En System Lab POS > Productos, cada producto tiene el campo Destino de
preparación. Seleccione Cocina, Bar / bebidas, una ruta personalizada o No
enviar a preparación. Esta selección se guarda una sola vez.

FUNCIONAMIENTO

- Al enviar un pedido a preparación, el POS separa automáticamente los
  productos y envía cada grupo a su impresora.
- Al cobrar, el comprobante completo sale por la impresora del cliente.
- Una impresora sin configurar nunca recibe trabajos de otra ruta como
  reemplazo; el POS muestra el error para evitar impresiones incorrectas.

IMPORTANTE

El comprobante impreso por el POS es de control interno. No sustituye una
factura electrónica autorizada por Hacienda.
